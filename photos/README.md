# Physical evidence

Everything else in this repo is geometry: a solid is rendered, boolean probes
are pushed into it, and the numbers are recorded. That catches a great deal —
a socket that would not accept an MX cross, a cap wider than its own key
pitch, an overhang that would need support — and it cannot catch anything
that only exists once plastic cools.

So this directory is for photographs of the models as actually printed, kept
separate from the validation output on purpose. **A photo is not a check.**
It is the thing a check cannot be.

## What a print proves, and what it does not

| | |
|---|---|
| it printed | the geometry is sliceable, the orientation works, no support was needed |
| it looks right | the profile, the dish and the legend are what the drawing said |
| **it fits** | **only confirmed by pushing it onto a real switch** |
| it survives | only confirmed by typing on it for a while |

The third row is the one that matters, and it is the one a photograph of a
build plate cannot answer. Until a cap has been seated on a switch, the
tolerances in `cross_clr_w` / `cross_clr_t` are still estimates — see the
provenance tables in each keyboard's README.
